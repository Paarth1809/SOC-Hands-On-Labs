# SOC Hands-On Labs

{% embed url="https://tryhackme.com/room/linuxfundamentalspart1" %}



A collection of hands-on Security Operations Center (SOC) labs documenting my practical cybersecurity learning journey.

This repository contains beginner to intermediate SOC projects focused on SIEM deployment, log collection, endpoint monitoring, threat detection, and security analysis. Each lab includes a report, screenshots, and key learnings.

***

## Objectives

* Develop practical SOC skills through hands-on labs
* Learn SIEM deployment and log management
* Gain experience with Windows security monitoring
* Document projects for learning and portfolio purposes

***
