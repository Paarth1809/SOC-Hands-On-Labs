# Log Analysis Basics

### Lab Environment

#### Windows

A Windows Server was used to create a test account and generate failed authentication activity.

#### Network Lab

The network portion uses two virtual machines:

| Role     | System       | IP                |
| -------- | ------------ | ----------------- |

| Target   | Ubuntu Linux | `192.168.241.131` |

## Network Log Analysis

### Requirements

* Attacker machine: kali linux
* Target Machine: Ubuntu linux

### Port Scanning

Port scanning is used to Scan Victims open ports by sending ICMP, packets to different port on te network\
Most poplular Tool for Port scanning is NMAP Tool

Types of NMAP Scan

* SYN Scan: Fast and Stealthy Scan
* TCP Connect: Full TCP Scan
* UDP Connect: UDP Scan
* Ping Scan: Checks Which hosts are up

### Configuring UFW

<figure><img src="../.gitbook/assets/image 6.png" alt=""><figcaption></figcaption></figure>

UFW was enabled and logging was turned on. This allows firewall activity to be recorded for later analysis.

#### **Create a Firewall Rule**

<figure><img src="../.gitbook/assets/image 7.png" alt=""><figcaption></figcaption></figure>

A UFW rule was created to deny HTTP traffic from the attacker IP `192.168.241.130` to port `80`.

#### **Monitor UFW Logs**

<figure><img src="../.gitbook/assets/image 8.png" alt=""><figcaption></figcaption></figure>

The UFW log was monitored in real time to observe network activity generated by the attacker machine.

#### **Analyze Filtered Traffic**

<figure><img src="../.gitbook/assets/image 9.png" alt=""><figcaption></figcaption></figure>

The UFW log shows traffic from source IP `192.168.241.130`, confirming that the firewall recorded the network activity from the attacker.
