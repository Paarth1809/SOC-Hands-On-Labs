# Windows Sysmon Installation and Log Collection with Splunk

**Date:** August 05, 2026

### Project Overview

In this lab, I installed and configured Microsoft Sysmon on a Windows endpoint and integrated its event logs with Splunk using the Splunk Universal Forwarder.

The goal was to generate detailed Windows system activity logs with Sysmon and forward Windows event logs to Splunk for centralized monitoring and analysis.

### Objectives

* Install Microsoft Sysmon
* Configure Sysmon using a configuration file
* Verify the Sysmon service is running
* Configure Splunk Universal Forwarder to collect Windows Event Logs
* Forward Windows logs to Splunk
* Verify successful log collection in Splunk

#### Step 6: Configuring Splunk Universal Forwarder

The Splunk Universal Forwarder configuration directory was accessed to configure Windows Event Log collection.

The `input.conf` file was configured to collect:

* Windows Security logs
* Windows Application logs
* Windows System logs
* Sysmon Operational logs

<figure><img src="../.gitbook/assets/Screenshot 2026-08-05 195612.png" alt=""><figcaption><p><strong>Figure 6: Splunk Universal Forwarder configuration</strong></p></figcaption></figure>

***

#### Step 7: Configuring Sysmon Event Log Input

The `input.conf` configuration included the Sysmon Operational event log:

```
[WinEventLog://Microsoft-Windows-Sysmon/Operational]
disabled=0
renderXml=true
checkpointInterval = 5
```

This enables the Universal Forwarder to collect events generated by Sysmon from the Windows Event Log.

### Results

Sysmon was successfully installed and configured on the Windows endpoint. The Sysmon service was verified as running, and the Splunk Universal Forwarder was configured to collect Windows Event Logs, including the Sysmon Operational log.

Splunk successfully received and indexed Windows event data from the endpoint. The Data Summary showed **5,003 events** from the Windows host across the Application, Security, and System sourcetypes.
